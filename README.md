# Marketing Attribution ROI Dashboard
Multi-Touch Marketing Attribution and ROI Analysis using Python, SQL, SQLite, and Power BI.

## Project Overview

The Marketing Attribution ROI Dashboard analyzes customer interactions across multiple marketing campaigns and channels to determine how marketing efforts influence conversions and revenue. Using campaign, customer, event, product, and transaction data, the project evaluates marketing effectiveness and provides actionable insights through an interactive business intelligence dashboard.

The dashboard provides business stakeholders with actionable insights that support data-driven marketing decisions and budget optimization.

---

## Business Problem

Organizations invest heavily in multiple marketing channels such as:

* Email Marketing
* Paid Search
* Social Media
* Direct Traffic
* Display Advertising

Without proper attribution analysis, it becomes difficult to determine which channels drive conversions and generate the highest return on investment (ROI).

This project addresses that challenge through data exploration, attribution analysis, KPI development, and dashboard visualization.

## Dataset

**Dataset Name:** Marketing & E-Commerce Analytics Dataset

**Source:** Kaggle

The project uses a comprehensive marketing and e-commerce analytics dataset containing customer information, marketing campaigns, customer interactions, product details, and transaction records. The dataset supports customer journey analysis and marketing attribution modeling across multiple touchpoints.

### Data Files

| File             | Description                                                                                                                       |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| campaigns.csv    | Marketing campaign information including campaign channels, objectives, start and end dates, target segments, and expected uplift |
| customers.csv    | Customer demographic and profile information                                                                                      |
| events.csv       | Customer interactions and engagement events across marketing channels                                                             |
| products.csv     | Product catalog and product-related attributes                                                                                    |
| transactions.csv | Customer purchase transactions and revenue data                                                                                   |

### Key Relationships

* `campaign_id` links campaigns with customer interactions and transactions.
* Customer records connect behavioral events to purchase outcomes.
* Transaction data enables revenue and ROI analysis.
* Event data supports multi-touch attribution modeling.

### Business Value

This dataset enables:

* Marketing channel performance analysis
* Customer journey mapping
* Conversion attribution analysis
* Campaign effectiveness evaluation
* ROI measurement and optimization
* Interactive dashboard development
