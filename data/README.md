# Dataset Access

Raw dataset files are not committed to this repository because `events.csv` is larger than GitHub's normal file size limit.

To reproduce the analysis, download the shared dataset files and place them inside the local `data/` folder.

## Required Local Files

- data/events.csv
- data/transactions.csv
- data/customers.csv
- data/products.csv
- data/campaigns.csv

## Data Limitation

The current shared datasets do not include ad spend data.

Therefore, true ROAS, CAC, CPC, and ROI cannot be calculated directly from the available files. The current analysis focuses on attribution, attributed revenue, funnel analysis, customer segmentation, and campaign/channel performance.

A synthetic `ad_spend.csv` file may be created later if the team approves.
